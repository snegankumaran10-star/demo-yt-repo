      How it works

      1. 1

        Read the PDF in the browser

        The file never leaves your machine. pdf.js pulls the text layer out of the document locally.

      2. 2

        Match it against a skill set

        Each entry in the catalog — HTML, React, testing, accessibility, and so on — has a pattern that is tested against the resume text.

      3. 3

        Score the overlap

        The score is the share of the target role's skills the parser found. Everything it looked for and could not find is listed as missing.
